## $CodeExampleName$

When a user double-click an item, the application takes them from the main **Items screen** to another View
where they can edit the TodoItem object properties. 

The layout of this screen is pretty straightforward: a set of editors that match TodoItem property types,
and a few buttons that allow users to save changes, delete the current item, or go back to the main application screen.
This screen includes its own `BindingSource` object. This object stores the currently processed `TodoItem` entity.
